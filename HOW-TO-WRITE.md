# Publishing an article

Write:   https://olekpoli.github.io/control/
New article, title, summary, text, drag images straight into the text, Publish.
The site updates in about a minute.

One-time login: GitHub > Settings > Developer settings > Personal access tokens >
Fine-grained tokens > Generate. Repository access: only olekpoli.github.io.
Permissions: Contents = Read and write. Paste the token on /control/ ("Sign in with token").
